# Web API 练习集

这是一个 Web API 练习项目的合集仓库，每个子文件夹是一个**完全独立**的小项目：各自有自己的依赖、配置和运行方式，互不影响，可以只下载/运行其中一个。

## 项目列表

| 目录 | 主题 | 技术栈 |
|---|---|---|
| [`product-demo/`](product-demo/README.md) | 认证（JWT）、分页、缓存 | Next.js + FastAPI |
| [`todo-app-demo/`](todo-app-demo/README.md) | REST API 设计（CRUD）、OpenAPI 文档、SQLite | Next.js（App Router API Routes） |

点进各自的 `README.md` 查看具体的运行步骤和练习说明。

## 只想要其中一个项目？

每个子文件夹都是自包含的，不依赖仓库根目录的任何文件。可以直接：

- 用 GitHub 网页的 "Download" 功能，或
- `git clone` 整个仓库后只进入你需要的那个子文件夹

都能独立运行，不需要仓库里的其他部分。
