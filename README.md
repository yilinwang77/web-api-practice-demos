# Web API 練習用リポジトリ

Web API の練習用プロジェクトをまとめたリポジトリ。各サブフォルダは**完全に独立**した1つのプロジェクトで、それぞれ独自の依存関係・設定・起動方法を持ち、互いに影響しない。どちらか一方だけをダウンロード・実行することも可能。

## プロジェクト一覧

| フォルダ | テーマ | 技術スタック |
|---|---|---|
| [`product-demo/`](product-demo/README.md) | 認証（JWT）・ページネーション・キャッシュ | Next.js + FastAPI |
| [`todo-app-demo/`](todo-app-demo/README.md) | REST API 設計（CRUD）・OpenAPI ドキュメント・SQLite | Next.js（App Router API Routes） |

具体的な起動方法や練習内容は、それぞれのフォルダの `README.md` を参照。

## どちらか一方だけ使いたい場合

各サブフォルダはリポジトリのルートにあるファイルに一切依存しない自己完結型の構成になっている。次のいずれかの方法で取得できる：

- GitHub の "Download" 機能で該当フォルダだけ取得する
- リポジトリ全体を `git clone` して、必要なサブフォルダにだけ移動する

どちらの方法でも、そのフォルダ単体で問題なく動作する。リポジトリの他の部分は不要。
